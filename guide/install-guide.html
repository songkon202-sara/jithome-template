ภาพรวม 6 ขั้นตอน

ขั้นทำที่ทำอะไรเวลา
1Supabaseสร้างฐานข้อมูล รัน install.sql และตั้งค่าการเข้าสู่ระบบ15 นาที
2Supabaseติดตั้งฟังก์ชันแจ้งเตือน 2 ตัว10 นาที
3GitHubคัดลอกชุดติดตั้ง แก้ config.js และเปิดเว็บ10 นาที
4Supabaseผูกที่อยู่เว็บกับฐานข้อมูล2 นาที
5เว็บของหน่วยงานสร้างบัญชีแอดมินคนแรก5 นาที
6หน้าแอดมินตั้งค่าหน่วยงาน นำเข้าผู้ป่วย เพิ่ม อสม.10+ นาที
💡 แนะนำทำทุกขั้นบนคอมพิวเตอร์ และเปิดคู่มือนี้คู่กันไป ทำตามลำดับ อย่าข้ามขั้น

ขั้นที่ 1 · สร้างฐานข้อมูล (Supabase)

1
สร้างโปรเจกต์ใหม่
  1. เข้า supabase.com → ล็อกอิน → กด New project
  2. ตั้งชื่อ เช่น jithome-ชื่อตำบล
  3. Region: Southeast Asia (Singapore)
  4. ตั้งรหัสผ่านฐานข้อมูล แล้วจดเก็บไว้ในที่ปลอดภัย
  5. กด Create new project แล้วรอ 1–2 นาที
2
รันไฟล์ติดตั้งฐานข้อมูล
  1. เปิดไฟล์ sql/install.sql ใน repo ชุดติดตั้ง → กด Copy raw file (หรือเลือกทั้งหมดแล้วคัดลอก)
  2. Supabase เมนูซ้าย SQL Editor → New query → วาง → กด Run
  3. ถ้ามีหน้าต่าง Potential issue detected ให้กด Run without RLS
    (ปลอดภัย สคริปต์เปิด RLS ให้ครบทุกตารางเอง)
  4. ผลที่ถูกต้อง: ตารางด้านล่างขึ้นคำว่า ติดตั้งเสร็จ
ถ้าขึ้น “ยังไม่ครบ: pg_net” หรือ “pg_cron” เมนู Database → Extensions → ค้นหาชื่อนั้น → เปิด → กลับมารัน install.sql อีกครั้ง (รันซ้ำได้ ไม่ลบข้อมูล)
3
ตั้งค่าการเข้าสู่ระบบ
  1. Authentication → Sign In / Providers → Email → ปิด Confirm email → Save
    (อสม. สมัครด้วยเบอร์โทร ไม่มีอีเมลจริง)
  2. Authentication → Multi-Factor → เปิด TOTP → Save
4
จด 2 ค่านี้ไว้ใช้ในขั้นที่ 3

Project Settings → API (หรือ API Keys)

  • Project URL เช่น https://abcdefghijkl.supabase.co
  • anon public key (ขึ้นต้น eyJ...) หรือ publishable key (ขึ้นต้น sb_publishable_...)
⛔ ห้ามใช้ service_role key / secret key กับเว็บเด็ดขาด key นี้เปิดข้อมูลได้ทั้งหมด ถ้าหลุดออกไป ใครก็อ่านข้อมูลผู้ป่วยได้

ขั้นที่ 2 · ติดตั้งฟังก์ชันแจ้งเตือน (Edge Functions)

Supabase → Edge Functions → Deploy a new function → Via Editor ทำทีละตัว:

  1. ลบโค้ดตัวอย่างในช่องแก้ไขออกให้หมด
  2. เปิดไฟล์ตามตารางใน repo → คัดลอกโค้ดทั้งหมด → วาง
  3. ตั้งชื่อฟังก์ชันให้ตรงตามตารางทุกตัวอักษร → เปิด Verify JWT ไว้ (ค่าเริ่มต้น) → Deploy
ชื่อฟังก์ชันวางโค้ดจากใช้ทำอะไร
notifysupabase/functions/notify/index.tsส่ง LINE / Telegram จากแอป
reset-aosomo-passwordsupabase/functions/reset-aosomo-password/index.tsแอดมินรีเซ็ตรหัสผ่าน อสม.

ขั้นที่ 3 · สร้างเว็บ (GitHub)

1
คัดลอกชุดติดตั้งมาเป็นของหน่วยงาน
  1. เปิด github.com/songkon202-sara/jithome-template
  2. กดปุ่มเขียว Use this template → Create a new repository
  3. ตั้งชื่อ เช่น jithome · เลือก Public (GitHub Pages แบบฟรีต้องเป็น Public) → Create repository
2
แก้ไฟล์ config.js (ไฟล์เดียวที่ต้องแก้)

ใน repo ใหม่ เปิดไฟล์ config.js → กดรูปดินสอ ✏️ → แก้ 4 ค่า:

SUPABASE_URL: 'https://abcdefghijkl.supabase.co',   // Project URL จากขั้นที่ 1
SUPABASE_ANON_KEY: 'eyJ...',                          // anon / publishable key
HOSPITAL_NAME: 'รพ.สต.บ้านตัวอย่าง',
VILLAGES: ['หมู่ 1', 'หมู่ 2', 'หมู่ 3', 'นอกเขต'],

→ กด Commit changes

💡 รายชื่อหมู่บ้านต้องสะกดตรงกับคอลัมน์หมู่บ้านในไฟล์รายชื่อผู้ป่วยที่จะนำเข้า เพราะระบบใช้ชื่อนี้กำหนดว่า อสม. เห็นผู้ป่วยหมู่ไหน
3
เปิดเว็บไซต์
  1. Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save
  2. รอ 1–2 นาที เว็บจะอยู่ที่ https://ชื่อบัญชี.github.io/ชื่อrepo/

ขั้นที่ 4 · ผูกเว็บกับฐานข้อมูล

Supabase → Authentication → URL Configuration

  • Site URL = ที่อยู่เว็บจากขั้นที่ 3
  • Redirect URLs → Add URL → ใส่ที่อยู่เดียวกัน → Save
    (ถ้าไม่ทำ ลิงก์ “ลืมรหัสผ่าน” ในอีเมลจะใช้ไม่ได้)

ขั้นที่ 5 · สร้างบัญชีแอดมินคนแรก

⏱ ทำขั้นนี้ทันทีหลังเปิดเว็บบัญชีแรกที่สมัครในระบบจะเป็นแอดมินอัตโนมัติ ถ้าคนอื่นสมัครก่อน คนนั้นจะได้เป็นแอดมิน
  1. เปิดเว็บ → สมัครสมาชิก ด้วยอีเมลของผู้ดูแลระบบ
  2. เข้าสู่ระบบ → ระบบให้ตั้ง 2FA → เปิดแอป Google Authenticator สแกน QR → กรอกรหัส 6 หลัก
  3. อ่านข้อตกลงรักษาความลับ → ติ๊กยอมรับ → ยอมรับและเข้าใช้งาน

ผู้ที่สมัครหลังจากนี้ทุกคนต้องรอแอดมินอนุมัติก่อนเข้าใช้งาน

เจ้าหน้าที่ (ต้องใช้ 2FA)ทั้งหมด✅✅—

ผู้สังเกตการณ์หน้าภาพรวม———

สิทธิ์ถูกบังคับที่ฐานข้อมูล (Row Level Security) ไม่ใช่แค่ซ่อนปุ่มบนหน้าจอ และระบบมีการป้องกันเพิ่มเติม:

  • ทุกคนต้องกดยอมรับข้อตกลงรักษาความลับทุกครั้งที่เข้าใช้งาน ระบบบันทึกเวลาไว้เป็นหลักฐาน
  • แอดมินระงับ / เปิดใช้งานบัญชีได้ในหน้าสมาชิก (ปุ่ม ⏸️ ระงับ) เช่น เมื่อ อสม. พ้นหน้าที่
  • ใส่รหัสผ่านผิด 5 ครั้ง บัญชีถูกล็อก 15 นาที
  • ไฟล์และรูปผู้ป่วยเปิดได้เฉพาะผู้ที่ล็อกอินแล้วเท่านั้น
  • ระบบสำรองข้อมูลผู้ป่วยอัตโนมัติทุกวัน เก็บย้อนหลัง 7 วัน

https://PROJECT.supabase.co/rest/v1/patients?select=id&limit=1&apikey=ANON_KEY

อาการวิธีแก้
เปิดเว็บแล้วขึ้น “ยังไม่ได้ตั้งค่า JitHome”ยังไม่ได้แก้ config.js หรือใส่ค่าผิด → แก้ตามขั้นที่ 3 แล้วรอ 1–2 นาที
หน้าต่าง “Potential issue detected” ตอนรัน SQLกด Run without RLS ได้เลย
ส่งแจ้งเตือนไม่ได้ / ขึ้น Unauthorizedตรวจชื่อ Edge Function ให้ตรง (notify) และเปิด Verify JWT · ตรวจ token ที่บันทึกในหน้าแอดมิน
Telegram ขึ้น “chat not found”ต้องเพิ่ม bot เข้ากลุ่มก่อน และใช้ Chat ID ของกลุ่ม (มักขึ้นต้นด้วย -)
ใส่รหัสผิด 5 ครั้ง บัญชีถูกล็อกรอ 15 นาที หรือแอดมินปลดล็อกในหน้าแอดมิน หรือรันใน SQL Editor:
DELETE FROM public.login_lockouts WHERE email = 'อีเมลที่ถูกล็อก';
ลิงก์ “ลืมรหัสผ่าน” ในอีเมลกดแล้วไม่ไปหน้าตั้งรหัสใหม่ยังไม่ได้ทำขั้นที่ 4 (Site URL / Redirect URLs)
ตั้งรหัสผ่านใหม่แล้วขึ้น “AAL2 session is required”บัญชีนั้นเปิด 2FA → กรอกรหัส 6 หลักจากแอป Authenticator ในช่องที่ขึ้นมา แล้วกดบันทึกอีกครั้ง
อีเมลขึ้น “invalid format”มีช่องว่างหรือตัวอักษรเกิน มักเกิดจากการคัดลอกวาง → ลบแล้วพิมพ์ใหม่เอง
อสม. เข้าได้ แต่ไม่เห็นผู้ป่วยเลยชื่อหมู่บ้านของ อสม. สะกดไม่ตรงกับทะเบียนผู้ป่วย (เช่น “หมู่ 1” กับ “หมู่1”) → แก้หมู่บ้านในหน้าสมาชิก
อสม. เห็นผู้ป่วยทุกหมู่บ้านยังไม่ได้กำหนดหมู่บ้านให้ อสม. คนนั้น
กดยอมรับข้อตกลงแล้วกลับมาหน้าเดิม / หน้าเว็บไม่อัปเดตมือถือยังใช้เวอร์ชันเก่า → ปิดแอปให้สนิทแล้วเปิดใหม่ หรือรีเฟรช 2–3 ครั้ง
Supabase แจ้งว่าโปรเจกต์ถูกพัก (paused)แผนฟรีพักโปรเจกต์เมื่อไม่มีการใช้งานราว 1 สัปดาห์ → เข้า Supabase กด Restore
